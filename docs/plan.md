# План приложения

1. Настроить React, JavaScript, Vite, Bootstrap, Redux Toolkit и React Redux; добавить ESLint и Prettier.
2. Реализовать прямые запросы к API Favorit, проверку ответа, сообщения об ошибках, отмену запросов и тайм-аут 20 секунд.
3. Организовать два этапа поиска в одном Redux slice: бренды по артикулу, затем предложения и аналоги по выбранному бренду. Защитить состояние от устаревших ответов.
4. Собрать один адаптивный экран с вводом артикула, ручным выбором бренда и таблицей предложений по складам. Добавить состояния ожидания, загрузки, ошибки, пустого и успешного ответа, повтор поиска.
5. Описать запуск и настройку ключа; проверить форматирование, ESLint и production-сборку командами `npm run format:check`, `npm run lint`, `npm run build`.

Все перечисленные части реализованы. Проверка успешного поиска в реальном API требует ключа.
