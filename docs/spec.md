# Спецификация

Одностраничное приложение на React и JavaScript использует Vite, Bootstrap, Redux Toolkit и React Redux. Состояние поиска хранится в одном slice.

## Поиск

1. Пользователь вводит артикул. Через 400 мс после последнего изменения отправляется GET к `https://api.favorit-parts.ru/hs/hsprice/` с параметрами `key` и `number`. Удаляются только пробелы по краям: ведущие нули и знаки сохраняются. Пустой артикул не вызывает запрос.
2. Из `goods` выводятся уникальные непустые бренды с исходными названиями. Пользователь выбирает бренд вручную.
3. Второй GET содержит `key`, `number`, `brand` и `analogues=on`. Таблица показывает товары и их аналоги: наименование, артикул, бренд, склад, цену и остаток.

Каждый склад занимает отдельную строку. Цена и остаток берутся из `warehouses.price` и `warehouses.stock` одной записи; поля товара их не заменяют. Нулевые значения сохраняются. Неизвестные значения обозначаются «Не указано», неизвестный склад — «Склад не указан». Для товара без складов выводится «Нет предложений по складам» с неизвестными ценой и остатком. Пустые записи не создают пустых строк. Символ валюты не добавляется.

## Состояния и запросы

Оба этапа имеют состояния ожидания, загрузки, ошибки и результата, включая пустой ответ. После ошибки доступен повтор текущего запроса. Изменение артикула немедленно очищает результаты обоих этапов и выбранный бренд; смена бренда очищает предложения.

Предыдущие запросы отменяются через AbortController. Redux принимает ответ только при совпадении текущих параметров и requestId, в том числе во время задержки перед новым запросом. Таймеры и контроллеры находятся вне Redux. Отмена не выводится как ошибка; превышение тайм-аута 20 секунд показывает отдельное сообщение.

Отсутствующий или отклонённый ключ, HTTP-ошибка, ошибка API, сбой сети и некорректный JSON или структура ответа показывают сообщения на русском языке.

## Интерфейс и настройка

Экран содержит подписанное поле ввода, кнопки выбора бренда, выделение выбранного бренда, статусы загрузки, сообщения об ошибках и адаптивную таблицу. Доступны управление с клавиатуры и видимый фокус.

Ключ задаётся переменной `VITE_FAVORIT_API_KEY` в `.env.local`. Запросы выполняются напрямую из браузера, поэтому ключ доступен пользователям клиентского приложения. Без ключа экран работает, а поиск сообщает о необходимости настройки. Работа с реальным API без ключа не проверена.
