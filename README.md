# Поиск автозапчастей

Приложение на React для поиска брендов, предложений и аналогов по артикулу.

## Запуск

Нужен Node.js 22.18.0 (версия указана в `.nvmrc`).

```bash
npm ci
cp .env.example .env.local
```

Укажите ключ в `.env.local`:

```dotenv
VITE_FAVORIT_API_KEY=ваш_ключ
```

```bash
npm run dev
```

Откройте адрес из вывода Vite. После изменения ключа перезапустите сервер разработки. Без ключа приложение открывается, а поиск показывает сообщение о настройке.

Ключ передаётся напрямую из браузера в HTTPS API Favorit и виден пользователям в запросах и клиентской сборке. `.env.local` исключён из Git, но это не скрывает ключ в браузере. Работа с реальным API без ключа не проверена.

## Команды

- `npm run dev` — сервер разработки.
- `npm run build` — сборка в `dist/`.
- `npm run preview` — локальный просмотр сборки.
- `npm run lint` — проверка ESLint.
- `npm run format` — форматирование Prettier.
- `npm run format:check` — проверка форматирования.
